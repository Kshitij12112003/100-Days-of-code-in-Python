📌 About This Repository

This repository documents my journey through the 100 Days of Code: The Complete Python Pro Bootcamp, taught by Angela Yu.

The goal of this challenge is to strengthen my Python programming skills through daily coding practice, hands-on projects, problem-solving exercises, and real-world applications.

Throughout this journey, I will explore Python fundamentals, automation, web development, data analysis, APIs, databases, and introductory machine learning concepts.

This repository will serve as my learning portfolio and demonstrate my progress as I develop practical programming skills.
